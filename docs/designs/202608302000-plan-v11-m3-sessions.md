  2. **会话 name 只存索引不落 meta**：session_meta 首行保持 v1.0 字段不变（type/session_id/created_at/workspace）；name 存索引，索引重建时从 JSONL 首条 user 消息派生默认名（前 20 字符，与自动命名同规则）。**已知边界（r1-S4）**：重建派生的是自动名，/rename 的手动命名在重建后丢失（手动命名仅存索引）——接受，TODO 登记偿还（meta 增字段为后续方案）。
  3. **token_used 口径**：v1.0 无会话累计记账——新增 `ReplContext.session_usage`（prompt/completion 会话累计，轮末由 turn_usage 累加）。生命周期：**/clear 重置**（新会话从零起算）；**/fork 继承当前值**（r1-B2 统一口径：分叉是新会话从 fork 点继续演进，token 统计延续；两处描述不得矛盾）；**切换会话时从索引 entry 恢复**。索引刷新时写入 token_used。
  4. **fork 语义**：`/fork <name>` 复制当前会话 JSONL → 新会话文件（meta 行 session_id 替换为新 id），**当前 REPL 切换到新会话**继续演进，原会话冻结在 fork 点（另存为语义）；历史节点分叉维持裁剪（FR-48）。
  5. **切换保护实现口径（r1-B1 修正）**：FR-50「Build 中阻止切换」落地为 `ctx.turn_active` 标志——**置位点在 repl 任务轮（调用 loop.run 之前）、复位点在 repl 轮末 finally**；`begin_turn()` 不触碰该标志（begin_turn 也被 /clear、/resume 调用，若在此置位且无 finally 复位，会导致切换命令永久误拒）。当前 REPL 单线程模型下轮间输入时恒为 False，该标志为防御性/前瞻性（FR-50 验收的可测形态：置位状态下三切换命令全部拒绝）。
  6. **agents 子会话不迁移不索引**：M2 的 `.glaucous/agents/` 是子 agent 运行留痕（可追溯用），不属于用户会话管理面；自动迁移只处理 `.glaucous/sessions/`，索引重建只扫用户级 project-hash 目录。
  7. **audit.log 双格式口径（r1-S1）**：现存两种行格式——审批管线行（`time/decision/agent/...`）与命令审计行（`at/event/...`）。/stats 决策分布**只统计含 `decision` 字段的行**（即审批决策），其余行跳过；统计口径写死不猜格式。

## 三、任务 3.2：sessions/index.py（FR-45/46）

### 3.1 索引数据模型（字段集 = 概设 §6.1 + per-entry 冗余 workspace，r2-S13 表述修正）

```python
@dataclass
class SessionEntry:
    id: str                 # 会话文件 stem（= session_id）
    name: str               # 自动名（首条 user 消息前 20 字符）或 /rename 覆盖值
    workspace: str          # 原工作区绝对路径（meta 记录）
    created_at: str         # ISO 时间（meta.created_at）
    updated_at: str         # 最近活动时间（轮末刷新 / 文件 mtime 兜底）
    message_count: int      # JSONL 消息行数（不含 meta 行）
    token_used: int         # session_usage 会话累计快照（prompt+completion）
    status: str = "active"  # 恒 active（v1.1 无归档语义，前向兼容概设字段集）
```

索引文件结构与概设 §6.1 一致：`{"version": 1, "projects": {"<hash>": {"workspace": str, "sessions": [entry dict]}}}`。

### 3.2 接口

```python
class SessionIndex:
    def __init__(self, path: Path | None = None): ...   # 默认 index_path()
    def load(self) -> tuple[dict, bool]:
        """读取索引；(index, corrupted)。文件缺失/JSON 损坏/结构不符 → corrupted=True。"""

    def rebuild(self, workspace: Path) -> dict:
        """损坏重建（降级路径明确，FR-45）：遍历 sessions_root() 全部 project-hash
        目录的 *.jsonl，逐文件读 meta 首行 + 全文统计（消息数、updated_at=文件 mtime、
        name=首条 user 消息前 20 字符），workspace 取 meta.workspace。写入并返回新索引。"""

    def upsert(self, entry: SessionEntry) -> None:
        """插入/更新单条（按 id 去重定位 project），原子写（tmp + replace）；失败尽力而为。"""

    def touch(self, session_id: str, workspace: Path, *, name: str | None = None,
              message_count: int | None = None, token_used: int | None = None) -> None:
        """轮末刷新（FR-45 写入时机）：updated_at=now，其余字段非 None 才覆盖；
        会话不在索引（如损坏重建前）→ 先按 workspace upsert 兜底再刷新。"""

    def remove(self, session_id: str) -> None: ...
    def all_sessions(self) -> list[SessionEntry]: ...          # 跨项目平铺
    def find_by_prefix(self, prefix: str, workspace: Path | None = None) -> SessionEntry | None:
        """id 前缀解析（r1-S2 三态消解，消解顺序固定）：
        ① workspace 非 None → 该项目内先精确 stem 命中，再前缀匹配（唯一才返回）；
        ② 未命中 → 全项目前缀匹配；
        ③ 多命中/零命中 → 返回 None（多命中由调用方取候选列表呈现，不猜测切换）。
        调用方需区分「多命中」时另行调 search/prefix 列表——提供
        prefix_candidates(prefix, workspace=None) -> list[SessionEntry] 供列表。"""
    def search(self, keyword: str) -> list[SessionEntry]: ...  # 名称子串搜索（跨项目）
```

- **写入时机**（概设 §6.1）：会话创建、首条用户消息自动命名、每轮结束刷新（updated_at/message_count/token_used）、/rename、/fork、迁移。全部**尽力而为**（失败打印一条 renderer 告警，不阻断对话）。
- **message_count**：直接用 `len(history.messages)`（内存权威，免读文件）。

### 3.3 自动命名（FR-46）

- 新会话首条用户消息进入时（repl 任务轮入口、begin_turn 之后）：索引 name 为空 → **命名候选 = task 首个非空行的前 20 字符；若该行以「请按照以下技能」开头（/skill 组装文本包装行，r1-S5）则顺延取下一个非空行**；经 touch 落库；
- /rename 随时覆盖（空参数报用法）；自动命名不覆盖已手动命名的会话（name 已存在则跳过）。

## 四、任务 3.3/3.5：命令面（FR-47/48/49/50/46）

### 4.1 `/sessions [kw]`（FR-47）

- **无参**：列表卡（make_card）——默认**当前项目**会话（倒序按 updated_at），行 = `名称 · 更新时间（相对） · N 条消息 · token`；尾行提示 `[a] 全部项目 · /sessions <kw> 搜索`；
- **kw == "a"**：全部项目列表（行首加 workspace 尾段，同项目聚组）；
- **kw 其他**：按 §3.2 三态消解（r1-S2）：①当前项目精确 stem → 切换；②前缀唯一（当前项目→全项目）→ 切换；③**多命中 → 列出候选列表（不切换，提示用更长前缀）**；④零命中 → `search(kw)` 名称子串搜索，跨项目显示结果列表（不切换）；搜索也空 → 「未找到匹配会话」；
- 空列表提示「暂无会话」。

### 4.2 `/rename <name>`（FR-46）

- 空参数 → 用法提示；更新当前会话索引 name（touch 覆盖），成功提示含新名称；索引失败降级告警。

### 4.3 `/fork <name>`（FR-48，收窄语义）

流程：

1. 切换保护检查（§4.5）；
2. 读当前会话 JSONL 全文 → 生成新会话文件（project_dir 下新 stamp-rand 名）→ **meta 行 session_id 替换为新 id**（其余行原样）；
3. 索引 upsert 新条目：**created_at 沿用原会话 meta.created_at（r1-S3：避免 rebuild 时跳变）**、name=参数或 `<旧名>-fork`、message_count/token_used 继承、updated_at=now；
4. `History.load(新文件, ctx.system_prompt)` **三元组解包**（history, meta_workspace, warnings，r1-S3）→ `ctx.history` 替换，**warnings 逐条 renderer.note 呈现**；**ctx.state 重置为启动默认（SessionState()）**（交付后对齐 r1-S8：切换类命令 state 不跨会话延续，与 /resume 统一）、`session_usage` 继承当前值（决策 3）、session_events 保留（回看连续性）→ `rebuild_loop(ctx)`（与 /clear、/resume 同一重建路径，D8）；
5. 提示「已分叉到新会话 <新id>（原会话保留）」。

### 4.4 `/stats`（FR-49）

统计卡（make_card 两个区块）：

- **当前会话**：名称/id、消息数按角色分布（user/assistant/tool，读 `history.messages`）、token 用量（session_usage 累计，显示 ↑prompt ↓completion）、活跃时长（created_at ~ updated_at）、审批决策分布（读 `<workspace>/.glaucous/audit.log`：按 `decision` 字段聚合计数，含 agent 维度小计 main/child-N；**无 agent 字段的行归入「未标注」桶（r2-S11，如 record_denial 产出的 plan_mode_blocked 行——审批管线格式但无 agent 字段）**）；
- **全局聚合**：索引全部 projects 汇总（会话数/消息数/token 总和）+ 各 workspace audit.log 决策分布汇总（存在才读，缺失跳过）。

### 4.5 切换保护（FR-50）

- `ReplContext.turn_active: bool = False`：**置位点 = repl 任务轮（调用 `loop.run` 之前）；复位点 = repl 轮末 finally（r1-B1：begin_turn 不触碰该标志——它也被 /clear、/resume 调用且无 finally 复位，若在此置位会导致切换命令永久误拒）**。
- 切换类命令（/sessions <id> 切换、/fork、/resume）入口检查：turn_active → 拒绝并提示「本轮任务执行中，无法切换会话」（防御性：当前 REPL 模型下输入处理发生在轮间，该标志恒为 False，为后续并发预留；FR-50 验收以「置位状态下三命令全部拒绝」的可测形态固化）。
- 切换/恢复完成后：`git status --porcelain`（cwd=workspace，subprocess，超时 5s）非空 → `renderer.note("⚠ 工作区有未提交修改（可能来自其他会话），可 git status 检查（/rollback 待 M4）")`；非 Git 工作区/命令失败 → 静默跳过。

### 4.6 命令登记

- `COMMAND_META` 增 4 条：/sessions「列出/搜索/切换会话」、/rename「重命名当前会话」、/fork「分叉当前会话（另存为语义）」、/stats「会话与全局统计」；
- `_COMMAND_USAGE`：/sessions → `/sessions [kw|id|a]`、/rename → `/rename <name>`、/fork → `/fork [name]`；
- `cli.SLASH_COMMANDS` 增 4 个；`ARG_COMPLETIONS` 增 `"/sessions": "session"`（kw 候选 = 当前项目会话名前缀过滤，动态取索引）。

## 五、任务 3.1 接线：启动与 resume 改造（FR-44/51）

### 5.1 `cli.repl()` 启动序列（在 history 创建/恢复之前）

1. `migrated = migrate_legacy_sessions(workspace)` → 非空逐行 `theme.note(日志)` + 汇总行「已迁移 N 个旧会话到用户级存储」；
2. 新会话路径：经**统一存储入口** `create_session_history(system_prompt, workspace)`（§5.4，r1-B3：覆盖全部 5 处新建会话调用点），返回二元组 `(history, degraded)` 解包；degraded=True 时 `theme.note` 告警；
3. 恢复路径：`resume_history(workspace, ...)` 内部改为用户级目录（§5.2），其内部**三处兜底 return 分支**（未找到/前缀未命中/恢复失败）也统一走 §5.4 入口；
4. 启动后首次 touch（把新/恢复会话登记进索引；恢复时 token_used 从索引恢复进 session_usage）。

### 5.2 `resume_history` / `find_latest_session` 改造

- `find_latest_session(workspace)`：glob 路径改 `project_dir(workspace)`；
- `--resume <id>` 前缀模糊匹配：同目录（当前项目）；
- `/sessions <id>` 跨项目切换：走 `SessionIndex.find_by_prefix` 拿到绝对路径 → `History.load(path, system_prompt)`（工作区不一致警告复用既有逻辑）；恢复的 token_used 写回 session_usage。

**切换后的 session_usage 恢复口径（r2-S10，适用于 /sessions 切换与运行中 /resume）**：索引只存 token_used 合计数（概设字段集），prompt/completion 不可分——恢复时 `session_usage = {"prompt": entry.token_used, "completion": 0}`（历史累计计入 ↑ 侧显示），touch 时 token_used = prompt+completion 保持单调不减，避免未恢复值覆写索引。

### 5.3 轮末刷新接线（repl finally）

- `ctx.session_usage` 累加本轮 turn_usage（prompt/completion）；

## 八、错误处理策略

| 场景 | 行为 |
|---|---|
| 索引文件缺失/JSON 损坏 | load 返回 corrupted → 列表/切换前触发 rebuild（降级路径明确，FR-45），提示「索引已重建」 |
| 索引写入失败（IO/权限） | 尽力而为：renderer 告警一条，对话继续 |
| 旧会话迁移中单文件失败 | 跳过该文件继续，日志注明；启动不阻断 |
| 迁移目标同名文件 | 视为同一会话：跳过移动、仍 upsert 索引 |
| /sessions kw 无 id 命中且搜索为空 | 提示「未找到匹配会话」 |
| /fork 当前会话无 JSONL（未落盘） | 不会发生（create 即落盘）；IO 失败 → 报错保持原会话 |
| 切换时 turn_active | 拒绝并提示（防御性，FR-50） |
| git status 不可用/非 Git 工作区 | 静默跳过未提交检测 |
| /stats audit.log 缺失或行损坏 | 跳过该文件/该行，统计按可得数据呈现 |
| ~/.glaucous 无法创建（极端环境） | **create_session_history 降级**（r1-S8）：返回 degraded=True + 回退 workspace 旧路径，调用方告警；迁移/索引静默降级，对话功能可用 |
| /stats audit.log 行无 decision 字段（命令审计行 at/event 格式） | 跳过不统计（决策 7 口径：只统计含 decision 的审批管线行） |

## 十一、实现对齐注记（代码评审 r1-S4/S8 作者确认，2026-08-30）

以下四处为实现相对 spec 字面的加法扩展/口径统一，经作者确认采纳：

1. **touch 增 auto_name 参数**（§3.2）：自动命名与显式 /rename 共用 touch——auto_name 仅在当前 name 为空时生效，实现「自动命名不覆盖手动命名」而无需读后写竞态；
2. **migrate 增 index 参**（§二）：迁移内直接 upsert，避免返回值二次接线；
3. **自动命名触发点在轮末 finally**（§3.3）：首条用户消息随首轮结束统一刷新（而非 run 前预插），口径等价；
4. **切换类命令（/sessions 切换、/fork、/resume）后 state 重置为启动默认**（§4.1/§4.3）：与 v1.1-M1 既有 /resume 语义统一，模式/授权策略不跨会话延续（§4.3 原「state 保留不变」作废）。
