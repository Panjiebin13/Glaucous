## 一、总体设计：模式状态机重构（概设 §4.1）

```
状态：BUILD（默认） | PLAN（研究）
启动 → BUILD；/plan → PLAN；/build [per-action] 或 submit_plan 批准 → BUILD
```

| | BUILD（默认） | PLAN（研究模式） |
|---|---|---|
| 语义 | 执行与修改 | 只读研究与方案讨论 |
| 工具 | 全部 | 写工具声明层隐藏（v1.0 机制复用）；bash 仅 SAFE 白名单 |
| 写操作 | 按授权策略（默认 auto-approve + 底线守卫） | 不存在 |
| 产出 | 代码修改、命令结果 | 分析结论与建议（对话形式） |

**与 v1.0 的关键差异**（本批落地项）：

1. **默认值翻转**：`SessionState` 默认 `mode=MODE_BUILD`、`approval_policy=POLICY_AUTO_APPROVE`——启动即处于 Build。
2. **「任务完成自动回归 Plan」退役**：Build 自然终止后**常驻 Build**，等待下一需求；loop 内 `return_to_plan` 调用点删除（含 mode_changed 发射），异常终止行为不变（本就无回归）。
3. **底线守卫从「例外」变「固有」**：`ApprovalPipeline.gate` 逻辑**零改动**——`POLICY_AUTO_APPROVE` 成为默认值后，auto-approve 分支（非守卫自动放行）与守卫例外（DANGEROUS、区外读永远单独确认）即默认路径固有行为（代码事实：approval.py L78~88）。
4. **mode_changed 事件保留统一出口**：loop.py L145~155 的「dispatch 后比对 mode 快照统一 emit」保留不动（其存在正服务于 PLAN 下 submit_plan 批准回 Build 的场景，r1-B1 裁决）；自然终止回归发射随回归分支一并删除。`mode_snapshot` 变量保留（L97/L127 仍有引用）。
5. **submit_plan 语义重造**：从「Plan 模式出口协议（三选一）」变为「高风险主动确认通道（二选）」，全模式可用（详见 §四）。
6. **授权策略生命周期简化**：策略仅经三处显式改变——`/build per-action`（设 per-action）、`/build auto-approve`（回切 auto-approve）、`/build`（无参=维持现状，仅切模式）。模式切换（/plan、/build 无参）**不再重置策略**；「同意同类型」豁免记录在进入 PLAN 时清空（策略作用域=构建期，语义保留）。

## 二、任务 1.1：默认模式/策略翻转（FR-35）

### 2.1 `permission/modes.py`

- `SessionState` 字段默认值：`mode: str = MODE_BUILD`；`approval_policy: str = POLICY_AUTO_APPROVE`。

- 常量 `POLICY_PER_ACTION`/`POLICY_AUTO_APPROVE`/`MODE_*`/`ALL_MODES` 不动（单一出口结构保留）。

### 2.2 `agent/loop.py`

- L105~116「Build 自然终止 → 回归 Plan」分支整体删除：自然终止序列变为 终答入史 → `_emit_budget()` → `return msg.text`；原 L107 的 `mode_snapshot` 比对仅服务回归发射，删除后无残留（`mode_snapshot` 本身在 L97/L127/L145 仍有引用，**保留**）。L145~155 dispatch 统一出口**保留不动**（§一 第 4 条）：PLAN 下 submit_plan 批准回 Build 时经此发射 mode_changed（payload：mode=build、policy=维持值），提示符/状态栏即时更新；BUILD 下批准比对为假不发射。mode_changed 事件类型为**活事件**（仅自然终止场景不再发生）。
- 终止条件①~⑤、守卫检查点、五类终止语义**零改动**（概设 §4.1「守卫检查点位置不变」）。

## 六、错误处理策略

| 场景 | 行为 |
|---|---|
| `/build` 非法参数（非空且非 auto-approve/per-action） | 报错提示用法，状态与策略不变 |
| `/build` / `/plan` 重复切换（已在目标模式） | 轻提示，不重复审计 mode_switch（现状 /plan 已如此，/build 对齐） |
| submit_plan 批准时处于 BUILD | 不触碰 mode/policy（幂等），仅回喂批准文案，不发射 mode_changed |
| 确认卡 EOF/Ctrl+C/Esc | 归为「修改意见」（feedback），模型停下修订；不视为批准 |
| PLAN 下模型幻觉调用写工具 | 声明层不可见 + 执行层拦截双保险（机制不变，文案更新） |
| 默认策略下 DANGEROUS/区外读 | 永远单独确认（gate 守卫优先级，代码不变，测试固化） |
