【如何运行】
环境：Python 3.11+。
1. 仓库目录执行：pip install -e .
2. 设置环境变量 GLAUCOUS_API_KEY（DeepSeek 或任意 OpenAI 兼容网关的密钥，凭据只经环境变量，不入库）；可选 GLAUCOUS_BASE_URL、GLAUCOUS_MODEL。
3. 执行：glaucous --workspace <你的项目目录>（或 ./start.sh）。
进入终端 REPL 后，用自然语言下达任务，agent 即自主读写文件、执行命令完成任务；输入 /help 查看全部命令；/model 可运行时切换模型。

【特色功能】
一、高自主。启动即 Build 模式并自动放行，任务交代清楚后自主跑完；仅高风险任务主动出方案卡请确认。
二、大任务全 Spec 流程。/spec 先以交互访谈澄清需求，用户确认清楚后生成书面规格（任务清单与结构化验收标准），经评审子 agent 审查（≤3 轮）后逐任务执行，执行后再经代码评审与逐条验收。评审由独立子 agent 承担，过程不占主上下文，仅回传千字内结构化报告。
三、四级上下文工程。超长工具输出截断落盘可回取、本地裁剪、模型摘要压缩、预算耗尽优雅终止，配合会话持久化与 /resume 跨会话续接，长任务数十步上下文占用仍极低。
四、安全兜底。每轮任务自动打 Git 快照（含未跟踪新增文件），/rollback 一键精确回退，审批卡支持「拒绝并回退」。权限矩阵按「有无兜底」划分：有快照兜底的区内写免审，区外写、运行时目录写、强制推送坚决拦截，危险命令逐段分类定级。
五、会话与扩展。会话用户级集中存储，/sessions 跨项目浏览切换，/fork 分支、/rename、/stats；glaucous.md 项目规则、事实记忆、技能系统（/skill 调用、创建后即时生效）。

【其它说明】
核心引擎全部自研，未使用任何 agent 框架：主循环与四类终止条件、流式工具调用拼装与解析熔断、对话历史持久化与上下文管理、工具定义与本地执行、错误处理（悬空调用善后防会话报废、指数退避重试）。依赖仅 openai（作 HTTP 通道）、rich 与 prompt_toolkit（终端渲染）。测试 336 个全部通过。
开发过程采用 spec 驱动：每个里程碑先写约束文档，经评审子代理多轮评审通过后再编码，代码再经评审循环；需求文档、概要设计、里程碑 spec 与 40 余份评审报告全部入库（docs/ 目录），每处设计决策可追溯、可辩护。
