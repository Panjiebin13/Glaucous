【如何运行】
环境：Python 3.11+。
1. 仓库目录执行：pip install -e .
2. 设置环境变量 GLAUCOUS_API_KEY（DeepSeek 或任意 OpenAI 兼容网关的密钥；凭据只经环境变量，不入库）；可选 GLAUCOUS_BASE_URL、GLAUCOUS_MODEL。
3. 执行：glaucous --workspace <你的项目目录>（或 bash start.sh）。
进入终端后以自然语言下达任务，agent 即自主读写文件、执行命令完成任务；/help 查看全部命令。

【特色功能】
设计宗旨：高自主地跑长任务、尽可能少打扰用户。
一、基础功能
1. 完整编程闭环：14 个本地工具（文件读写编辑、目录列表、全文搜索、shell 执行、向用户提问等），流式输出、思考过程折叠展示（/expand 回看）、终答 Markdown 渲染；
2. 交互体验：审批、提问、方案卡支持箭头键选择，状态栏显示模型、模式与上下文占用，/view 按类型查看工作区文件；
3. 会话管理：会话用户级集中存储，/resume 断点续接、/sessions 跨项目浏览切换、/fork 分叉会话讨论需求、/stats 统计；
4. 记忆与规则：双作用域事实记忆（全局+项目）跨会话沉淀环境事实，glaucous.md 双层规则全量注入永不裁剪，技能系统惰性加载、/skill 调用，/init 生成规则草稿；
5. 模型管理：注册表声明多模型档案，/model 经连通性校验后运行时热切换，会话历史无缝延续。
二、五大基座
长任务三座：
1. 上下文工程：三级压缩（本地裁剪、模型摘要、预算优雅终止），输出侧超长内容截断落盘随时回取；锚机制使方案全文落盘不常驻、压缩后目标不丢，长任务上下文峰值占用极低；
2. 子 agent 隔离：评审等重活在独立上下文执行，只回传千字内结构化报告（超限落盘可回取），主上下文不被污染，Spec 评审、代码评审、验收核验全自动；
3. Spec 任务分解：/spec 先访谈澄清需求，再生成书面规格（任务清单+验收标准），经子 agent 评审（≤3 轮）后逐任务执行，再经代码评审与逐条验收；状态即文档、中断可续跑。
高自主两座：
4. 权限矩阵：核心判据「有无兜底」——Git 工作区内写入免审，区内危险命令降级可确认；区外写、.glaucous 写、强制推送恒拦；bash 命令动态分类定级；启动即 Build 自动放行，执行期零审批弹窗；
5. Checkpoint 回退：每任务入口自动打 Git 快照（临时索引法，含未跟踪新增文件），保留 50 个，/rollback 一键精确还原并展示变更清单，审批拒绝可联动回退。
