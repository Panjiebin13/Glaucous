# Glaucous — 天青色夏日主题设计（CLI 视觉规范）

> 主题哲学：**“天青色等烟雨，而我在等代码通过。”**
> 每个元素都是从「雨过天青的晴空 + 海鸥掠过 + 夏日海风」的画面里取色。让开发者在深色终端里打开 Glaucous 时，一眼感受到清凉与通透。

---

## 1. 品牌色板

| 角色         | 色值                  | 出处                       | 用途                                    |
| ------------ | --------------------- | -------------------------- | --------------------------------------- |
| **天青主色** | `#3AA6B9`（雨过天青） | 汝窑天青釉，晴雨初霁的天空 | 主色：标题、强调、进度条主体、品牌 logo |
| **海鸥白**   | `#EAF4F4`（海泡沫白） | 海鸥腹羽、浪尖泡沫         | 正文、高对比文字                        |
| **深海蓝**   | `#1B2A4A`（夜海）     | 深海/暮色                  | 背景基底（深邃但不压抑，像夏夜的海面）  |
| **海盐青**   | `#9BD1D9`（浅青）     | 近岸浅海                   | 次级文字、次要信息、代码注释            |
| **晚霞橙**   | `#F4A261`（落日暖阳） | 海边落日                   | 警告、需注意项（少量点缀）              |

## 3. 终端兼容与降级

| 终端类型                                                    | 处理                                                              |
| ----------------------------------------------------------- | ----------------------------------------------------------------- |
| 支持 truecolor（VS Code、Windows Terminal、kitty、Ghostty） | 完整 24bit 配色                                                   |
| 支持 256 色                                                 | 映射到最近 256 色调色板                                           |
| 仅 16 色（老旧终端）                                        | 自动降级为白底/黑底 + 加粗，保证可读性（默认深色 `#1B2A4A` 背景） |

**实现**：所有颜色走 `rich` 的 `Style`/`Color` 抽象 + 一套 `theme.py` 定义色板常量，统一出口，不散落硬编码。后续可加 `/theme` 命令切换暗/亮模式（亮模式 = 天青底 + 深字）。

## 4. 命名与品牌资产

- **产品名**：Glaucous
- **命令**：`glaucous`
- **一句话定位**：_“雨过天青，海鸥滑翔，代码自有清凉。”_
- **CLI 内元素命名**：
  - 用户提问卡片 → 「🕊 想请教你」· 海鸥意象
  - 后台任务 → 「☁ 在后台飘着」· 天青云意象
  - 上下文压缩 → 「🌊 潮汐」（自动压缩时提示「涨潮了，压缩上下文」）
  - 会话恢复 → 「🌅 落日之后，海面依旧」· 复现故事感

> 品牌气质：不炫技、不压迫，像海鸥一样**轻盈、精准、不拖泥带水**。代码出错时不是红色警报，而是“海浪卷过，重新再来”的从容。

## 5. 与产品亮点的呼应（答辩可用）

> “我们的主题叫 Glaucous——天青色和它双关的海鸥。天青色是底色，代表这个 agent 的克制与清凉：权限边界、审批流、上下文管理，都是在**不让它失控**的前提下让它自由飞翔。海鸥是姿态：低空掠过、精准落点，不偏离用户的工作区边界。整个界面的每一处颜色，都在传达同一个产品哲学——**可控的自由**。”
