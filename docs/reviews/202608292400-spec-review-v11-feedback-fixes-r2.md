## 三、建议问题

### S8. §4.2 动态区窗口构成表述未随 B4 豁免同步收窄（表述级残留）
- **维度**：结构与可执行性（内部自洽）× 概设一致性
- **spec 位置**：§4.2「text 增量不再直接打印：一律 append 进动态区滚动行（**与 非 text 事件共用 8 行滚动窗口**，正文追加为滚动行尾部，视觉等同流式生成中）」
- **对内冲突点**：§4.4 步骤 2「**diagnostic 事件不进动态区**、始终即时直接打印（loop 契约『终止诊断必达』……）（B4 修复）」
- **说明**：B4 豁免后 diagnostic 已不共用滚动窗口，§4.2 括号内的窗口构成措辞未同步收窄，两处字面冲突。§4.4 步骤 2 为后出、更具体且附「必达」契约理由，实现者不会因此产生实际歧义（现状 `render_event` 的 diagnostic 分支 cli.py L511~513 即为直打，B4 豁免与现状管线一致），故按速查表记建议、不判阻塞。
- **修复方向**：§4.2 括号内措辞收窄为「与其余非 text 事件共用」，或加注「diagnostic 例外见 §4.4 步骤 2」。

### S9. 折叠行 N 口径与 B3/B4 新路径存在两处计数边角歧义
- **维度**：结构与可执行性（口径完备）
- **spec 位置**：§4.3「折叠摘要行 N 口径：显示本轮**动态区收纳条目总数 = 非 text 事件 + 交互伪事件 + 正文段落账条目**（……空正文段不落账不计数）」；§4.4 步骤 2「diagnostic 事件**不进动态区**」；§4.4 步骤 5「当前段正文缓冲落账为思考过程条目后清空」——该落账按固定顺序发生在 finally 步骤 1（收缩行渲染）之后
- **说明**：① diagnostic 按构成式（非 text 事件）应计入 N，按「动态区收纳条目总数」的口径语又不应计入，两种读法数值差 1；② 异常轮的正文段落账条目按构成式属「本轮正文段落账条目」，但落账发生于收缩行已渲染之后，不可能进入已显示的 N。两处均为轮末显示计数的边角，不影响主链路时序与 /expand 数据正确性，记建议。
- **修复方向**：§4.3 N 口径补一句例外说明（如「diagnostic 条目与异常路径步骤 5 的落账条目不计入 N」），或显式声明按构成式计入并接受收缩行少计 1 的边角。
