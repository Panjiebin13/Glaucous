## 三、「重要逻辑自行编写」五项（赛事点名项）

| 要求自研项 | 实现机制 | 关键位置 |
|---|---|---|
| **对话历史与上下文管理** | JSONL 逐条持久化 + 四级上下文预算工程（L0 输出截断落盘回取 / L1 本地裁剪 / L2 模型压缩 / 预算耗尽优雅终止）+ 方案/Spec 轻量锚 | `context/history.py`、`budget.py`、`compactor.py`、`safety/output_limit.py` |

| **模型输出的解析** | 流式 tool_calls 按 index 分桶拼装碎片→json.loads；网关兼容降级；连续解析失败 3 次熔断 | `llm/client.py`（_chat_once）、`tools/base.py`（ParseCircuitBroken） |
| **循环终止条件** | 四类：①自然终止（无 tool_calls）②步数上限 50 ③解析熔断 ④预算耗尽；守卫固定前置于每次 LLM 请求；诊断事件必达 | `agent/loop.py`（run/_terminate） |
| **错误处理** | 悬空 tool_call 强制善后（协议合法性）；网络层指数退避+抖动重试（4 次，4xx 不重试）；工具级失败回喂不终止；设施级尽力而为+一次性告警 | `agent/loop.py`（_salvage_dangling_calls）、`llm/client.py`（chat） |
