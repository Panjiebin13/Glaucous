# 发布前检查单

发布前按序核查，每项给出「通过 / 未通过 + 依据」：

1. **版本号**：版本声明（如 pyproject.toml / package.json）已按语义化版本递增。
2. **变更日志**：本次发布的功能、修复、破坏性变更已登记（CHANGELOG 或提交记录）。
3. **依赖**：新增依赖已声明且版本区间合理；无本地路径依赖残留。
4. **构建**：构建/打包命令可在干净环境执行成功（先看脚本再建议执行）。
5. **测试**：测试全绿；跳过的用例有理由说明。
6. **残留**：无调试输出、临时文件、未提交的生成物。

核查完成后汇总：就绪 → 给出发布步骤建议；未就绪 → 列出阻塞项清单。
