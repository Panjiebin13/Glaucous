你正在帮助用户创建一个新技能（skill）。技能 = 一个目录 + 一份 SKILL.md，供你在未来遇到匹配场景时经 load_skill 加载正文执行。

## 创建步骤

1. **确认用途与触发场景**：先向用户确认这个技能要解决什么问题、什么情况下应该触发。信息不足时调用 ask_user 具体请教，不要凭空假设。
2. **确定技能名**：目录名用小写字母、连字符分隔（如 `release-notes`、`db-migration-check`），名字应能表达用途。
3. **写入文件**：在当前工作区创建 `.glaucous/skills/<name>/SKILL.md`（只创建在工作区内，绝不写工作区之外的路径）。注意：写文件工具仅在 Build 模式可用——若当前是 Plan 模式，先声明进入 Build。
4. **文件模板**：

```
---
name: <name>
description: <一句话触发场景描述：写清"什么情况下使用本技能"，这是索引里模型判断是否加载的唯一依据>
---

<正文：给未来执行者的指令。写清目标、步骤、约束与验收标准；避免引用会话外的隐式知识。>
```

   要求：
   - frontmatter 以 `---` 开始并以 `---` 闭合，`name` 必须与目录名一致，`description` 必须是明确的触发场景句（不要写成"这是一个技能"这类无信息描述）。
5. **自校验**：写完后用读文件工具复读一遍，确认 frontmatter 完整、name 与目录一致、正文非空。
6. **告知用户**：说明技能已创建、触发方式（说出与 description 匹配的需求即可），并明确提示——新技能在下次 `/clear` 或重启会话后生效（技能索引在会话启动时扫描）。
