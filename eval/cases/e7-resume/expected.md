# E7 跨会话续接 · 执行说明（半自动）

验证长任务的会话中断恢复：大任务中途退出，`--resume` 续接后能复述进度
并完成剩余工作（终态与 e2 同口径）。

## v1.1 组步骤

1. `bash eval/run_case.sh e7-resume`（交互式运行）；
2. 在 agent 完成 1~2 项子任务后（如已修 add、正在写测试）输入 `/exit` 退出；
3. `glaucous --resume`（会话索引选择刚才的会话）继续同一工作区；
4. 观察：续接首轮 agent 是否能**说出已完成进度**（已完成哪些、剩哪些）
   ——记入报告（续接质量证据）；
5. 任务完成后运行 `bash eval/cases/e7-resume/check.sh /tmp/eval-e7-resume-<时间戳>`，预期 `PASS`；
6. 记录：续接是否重复执行已完成步骤（浪费 token）或遗漏剩余步骤。

## v1.0 组步骤（对照组）

1. 同上 1~2（v1.0 有 --resume 但无会话索引，需手工找出会话文件）；
2. 记录：找到并恢复会话的操作步骤数（对比 v1.1 的索引选择）；
3. 续接后同样观察进度复述与重复执行情况；
4. 运行同一 `check.sh`。

## 对比叙事（写进报告）

- v1.1：会话索引 + 进度可视，续接成本低；终态判定与 e2 完全同口径，可横向比较；
- v1.0：恢复成本高（手工定位会话文件），续接后上下文质量依赖运气；
- 该用例支撑「长任务」主线：真实长任务几乎必然跨会话。
